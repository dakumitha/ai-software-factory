Connect compute: checklist

To run code remotely while using your phone as the control surface, the platform needs a secure worker endpoint and authentication. This interface is not connected to one yet.

  1. Choose a permitted free worker route.
  2. Verify model access and its real cost before enabling an agent.
  3. Keep the worker isolated from production secrets.
  4. Connect through an authenticated backend, never expose the development API publicly.
  5. Run a harmless test task and verify its logs before enabling code changes.
