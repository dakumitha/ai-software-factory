# Architecture Decision Records

Store consequential technical decisions in this directory using numbered files such as `0001-select-orchestration-engine.md`.

Each decision should include:
- Status: proposed, accepted, superseded, or rejected.
- Context and constraints.
- Options considered.
- Decision and evidence.
- Security, privacy, licence, maintenance, and cost implications.
- Consequences, reversibility, and review triggers.

Prefer evidence from repository inspection and a small reproducible test over popularity or assumptions.
